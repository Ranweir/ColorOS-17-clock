# Glass Clock Widget

Tall, frosted-glass home-screen clock widget for Android.

- Tall condensed digits (custom font bundled in `app/src/main/assets/GlassDigits.ttf`)
- Frosted gradient fill with a thin glass edge
- Soft pink glow on the hour digits, blue glow on the minutes
- Hour "1" shown in red
- Date on top (`29 Oct Thu`)

## Build

Push to GitHub. The **Build APK** workflow runs automatically.
Download the APK from **Actions → latest run → Artifacts → GlassClock-debug-apk**.

Local build (Android Studio): open the folder and run `assembleDebug`.

## Install

Install the APK, long-press the home screen → Widgets → **Glass Clock** → drag it onto the screen.
